
## deepagents-ts specifics

- Docs root: `https://docs.copilotkit.ai/deepagents`, the same pages as the Python
  harness. Backend: Node / TypeScript (`npm run typecheck`).
- **Implement the TypeScript variant only.** Where a page shows Python and
  TypeScript tabs, or a Code tab with Python files, use the TypeScript code.
  If a page publishes only Python for something, that's a doc gap for this
  repo: record it and don't translate the Python yourself.
